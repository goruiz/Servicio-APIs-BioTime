FLUJO DE DATOS
==============

HTTP Request (GET /api/v1/employees)
    ↓
[FastAPI Router] app/api/v1/routes/employees.py
    ↓ Inyección de dependencias
[Service Interface] app/services/interfaces/biotime_service.py
    ↓ Implementación
[Service] app/services/implementations/biotime_service.py
    ↓ Llamada HTTP
[HTTP Client] app/clients/biotime_client.py
    ↓ JWT Auth
[BioTime API] http://biotime-server/personnel/api/employees/
    ↓ JSON Response
[Pydantic Schemas] app/schemas/biotime/employee.py
    ↓ Serialización
HTTP Response (JSON)


PRINCIPIOS SOLID APLICADOS
===========================

✅ Single Responsibility: Cada módulo tiene UNA responsabilidad
✅ Open/Closed: Extensible mediante interfaces sin modificar código
✅ Liskov Substitution: Implementaciones intercambiables
✅ Interface Segregation: Interfaces específicas, no genéricas
✅ Dependency Inversion: Dependencia de abstracciones, no detalles


ENDPOINTS DISPONIBLES
=====================

Health:
  GET  /health                          - Health check del servicio

Empleados:
  GET  /api/v1/employees                - Lista paginada de empleados
       Query params: ?page=1&page_size=10

Documentación:
  GET  /api/v1/docs                     - Swagger UI
  GET  /api/v1/redoc                    - ReDoc
  GET  /api/v1/openapi.json             - Especificación OpenAPI


COMANDOS ÚTILES
===============

Iniciar aplicación:
  python -m app.main
  # o
  uvicorn app.main:app --reload

Instalar dependencias:
  pip install -r requirements.txt

Tests:
  pytest                                 # Todos los tests
  pytest tests/unit                      # Solo unitarios
  pytest tests/integration               # Solo integración
  pytest --cov=app                       # Con cobertura

Linting y formato:
  black app/ tests/                      # Formatear código
  isort app/ tests/                      # Ordenar imports
  flake8 app/ tests/                     # Linting
  mypy app/                              # Type checking
